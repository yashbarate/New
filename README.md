# ThermaSense — Smart Comfort Fan

A responsive engineering project showcase website for the **AI-Based Thermal Comfort Control Fan System**.

## Files
- `index.html` — website content and structure
- `style.css` — responsive styling, visual effects, and animations
- `script.js` — mobile navigation, scroll reveal, and current year

## Preview locally
Open `index.html` in a browser. An internet connection is needed to load the Google Fonts; the website otherwise uses local files.

## Publish with GitHub Pages
1. Sign in to https://github.com/ and create a **public** repository named `thermasense-fan`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes and refresh the Pages section. Your site should be available at:

   `https://YOUR-USERNAME.github.io/thermasense-fan/`

Replace `YOUR-USERNAME` with your GitHub username. The URL above is a template, not a live link until you publish the repository.

## Before submitting
- Replace the sample email `your-email@example.com` in `index.html`.
- Add your name, team, college, circuit diagram, prototype images, and verified test results if needed.
- Keep project claims aligned with what you actually built and tested.

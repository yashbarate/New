01 / PROJECT OVERVIEW

Cooling with a little more intelligence.

Instead of relying only on a fixed fan setting, the proposed system considers the environment and whether a person is present.

⌁

The idea

Measure temperature and humidity, detect a person in the operating range, and use a controller to select a suitable fan-speed level. A connected wearable/app concept can provide additional user data when available.

Sensor inputPresence awareAdaptive output
◎

Project objective

Explore a practical, affordable approach to personal cooling that can respond to changing conditions and reduce unnecessary fan operation when no person is detected.

See the workflow →
✳

Design principle

Use environmental readings and presence information as inputs, then apply defined control logic or a lightweight machine-learning model to estimate a suitable speed.
